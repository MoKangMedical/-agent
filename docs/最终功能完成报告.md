## 📊 API端点总览

### 论文管理 (4个)
- `POST /api/papers/upload` - 上传论文
- `GET /api/papers/{id}` - 获取论文详情
- `GET /api/papers` - 论文列表
- `DELETE /api/papers/{id}` - 删除论文（待实现）

### 期刊推荐 (3个)
- `POST /api/journals/recommend` - 智能推荐期刊
- `GET /api/journals/search` - 搜索期刊
- `GET /api/journals/{name}` - 期刊详情

### 投稿管理 (3个)
- `POST /api/submissions/create` - 创建投稿
- `GET /api/submissions/{id}/status` - 查询状态
- `GET /api/submissions` - 投稿列表

### 数据导出 (3个) NEW!
- `GET /api/export/papers` - 导出论文数据
- `GET /api/export/submissions` - 导出投稿数据
- `GET /api/export/all` - 导出所有数据

### 统计分析 (1个) NEW!
- `GET /api/statistics` - 获取统计数据

### 系统 (2个)
- `GET /health` - 健康检查
- `GET /` - API信息

**总计: 16个API端点** ✅

```bash

curl http://localhost:8000/api/export/papers

点击仪表盘上的"导出"按钮
```

**导出文件位置:**
```

└── statistics_20260205_103725.txt
```

### 2. 邮件通知系统

**功能:**
- 投稿创建通知
- 状态更新通知
- HTML格式邮件
- 美观的邮件模板

**配置方式:**
在`.env`文件中添加：
```bash
SMTP_SERVER=smtp.gmail.com
SMTP_PORT=587
SENDER_EMAIL=your_email@gmail.com
SENDER_PASSWORD=your_app_password
```

**使用示例:**
```python
from email_notifier import EmailNotifier

notifier = EmailNotifier()
notifier.send_submission_created(
    to_email="user@example.com",
    paper_title="My Paper",
    journal_name="Nature",
    submission_id=1
)
```

## 🎓 使用示例

### 完整工作流程

**1. 上传论文**
- 访问 http://localhost:3001
- 选择PDF文件
- 填写标题、作者、摘要
- 点击"上传并获取期刊推荐"

**2. 查看推荐**
- 系统自动提取关键词
- 显示Top 5推荐期刊
- 查看匹配度、影响因子等

**3. 创建投稿**
- 选择合适期刊
- 点击"投稿到此期刊"
- 输入账号密码
- 创建投稿记录

**4. 跟踪进度**
- 切换到"投稿仪表盘"
- 查看统计数据
- 查看投稿列表
- 点击"查看详细统计"

**5. 导出数据**
- 点击"导出论文数据"
- 或"导出所有数据"
- 文件保存到data/exports目录

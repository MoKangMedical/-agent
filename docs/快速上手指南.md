# 🎓 PaperSubmit AI 桌面Agent - 5分钟快速上手

## 📝 使用步骤

### 步骤1️⃣：启动Agent

打开终端，运行：

```bash
cd ~/Desktop/论文投稿Agent
./start_agent.sh
```

你会看到：
```

📁 监控文件夹: /Users/linzhang/Documents/Papers
🚀 启动Agent...
✅ Agent初始化完成
🤖 Agent开始运行...
⏰ 扫描间隔: 300 秒
```

**Agent现在正在运行，每5分钟自动扫描一次！**

---

### 步骤2️⃣：放入你的论文PDF

打开Finder，找到 `~/Documents/Papers` 文件夹（Agent会自动创建）

**方法1：拖拽**
- 直接把你的PDF文件拖进这个文件夹

**方法2：复制**
```bash
cp /path/to/your/paper.pdf ~/Documents/Papers/
```

**例如：**
```bash
cp ~/Downloads/my_research_paper.pdf ~/Documents/Papers/
```

### 步骤5️⃣：创建投稿（可选）

如果你决定投稿到某个期刊，创建一个投稿信息文件：

**文件名格式：** `{论文名}_投稿信息.json`

**例如：** `my_research_paper_投稿信息.json`

**内容：**
```json
{
  "journal_name": "arXiv",
  "username": "your_arxiv_username",
  "password": "your_arxiv_password",
  "notes": "第一次投稿，选择arXiv因为审稿快"
}
```

**创建方法1：用文本编辑器**
1. 在 `~/Documents/Papers/` 创建新文件
2. 文件名：`my_research_paper_投稿信息.json`
3. 粘贴上面的内容，修改你的账号密码

**创建方法2：用命令行**
```bash
cat > ~/Documents/Papers/my_research_paper_投稿信息.json << 'EOF'
{
  "journal_name": "arXiv",
  "username": "your_username",
  "password": "your_password",
  "notes": "第一次投稿"
}
EOF
```

## 💡 使用技巧

### 技巧1：立即触发扫描（不等5分钟）

```bash
cd ~/Desktop/论文投稿Agent/src/backend
source venv/bin/activate
python desktop_agent.py --folder ~/Documents/Papers --once
```

### 技巧2：查看Agent日志

```bash
cat ~/Documents/Papers/.papersubmit/agent.log
```

### 技巧3：查看所有论文数据

```bash
cat ~/Documents/Papers/.papersubmit/papers.json
```

### 技巧4：查看所有投稿记录

```bash
cat ~/Documents/Papers/.papersubmit/submissions.json
```

### 技巧5：修改扫描间隔

编辑配置文件：
```bash
nano ~/Desktop/论文投稿Agent/src/backend/agent_config.json
```

修改 `check_interval` 值（秒）：
```json
{
  "check_interval": 60  // 改为1分钟扫描一次
}
```

## 🔍 常见问题

### Q1: Agent没有发现我的PDF？

**检查：**
- 文件是否真的是PDF格式？
- 文件名是否以`.`开头（隐藏文件）？
- Agent是否正在运行？

**解决：**
```bash
# 手动触发扫描
cd ~/Desktop/论文投稿Agent/src/backend
source venv/bin/activate
python desktop_agent.py --folder ~/Documents/Papers --once
```

### Q2: 推荐报告没有生成？

**检查日志：**
```bash
cat ~/Documents/Papers/.papersubmit/agent.log
```

**常见原因：**
- PDF文件损坏
- PDF没有可提取的文本
- 权限问题

### Q3: 投稿信息没有被处理？

**检查：**
- 文件名格式：`{论文名}_投稿信息.json`
- JSON格式是否正确？
- 必填字段是否完整？

**验证JSON格式：**
```bash
python3 -m json.tool ~/Documents/Papers/your_paper_投稿信息.json
```

### Q4: 如何停止Agent？

```bash
# 找到Agent进程
ps aux | grep desktop_agent

# 停止进程
kill <PID>
```

或者直接按 `Ctrl+C`（如果在前台运行）

## 📖 功能使用指南

### 功能1: 上传论文并获取推荐

1. **打开前端页面**  
   访问 http://localhost:3001

2. **上传论文**
   - 点击"📤 上传论文"标签
   - 选择PDF文件
   - 填写论文标题、作者、摘要
   - 点击"上传并获取期刊推荐"

3. **查看推荐结果**
   - 系统自动提取关键词
   - 显示Top 5推荐期刊
   - 每个期刊显示：
     - 综合评分
     - 匹配度
     - 影响因子
     - 审稿时间
     - 接收率
     - 投稿系统

4. **创建投稿**
   - 点击期刊卡片上的"投稿到此期刊"按钮
   - 输入投稿系统用户名和密码
   - 系统自动创建投稿记录

### 功能2: 投稿仪表盘

1. **切换到仪表盘**  
   点击"📊 投稿仪表盘"标签

2. **查看统计数据**
   - 总投稿数
   - 待处理数量
   - 已提交数量

3. **查看投稿列表**
   - 论文标题
   - 投稿期刊
   - 当前状态
   - 创建/更新时间

### 功能3: 期刊搜索

1. **切换到搜索**  
   点击"🔍 期刊搜索"标签

2. **搜索期刊**
   - 输入关键词（如：machine learning, biology）
   - 点击"搜索"按钮

3. **查看结果**
   - 期刊名称
   - 影响因子
   - 审稿时间
   - 接收率
   - 研究领域关键词
   - 期刊网站链接

## 🎯 完整工作流程

### 典型使用场景

```
1. 上传论文
   ↓
2. 获取期刊推荐
   ↓
3. 选择合适期刊
   ↓
4. 创建投稿记录
   ↓
5. 系统自动跟踪状态
   ↓
6. 在仪表盘查看进度
```

### 示例：投稿一篇机器学习论文

**步骤1: 准备材料**
- 论文PDF文件
- 论文标题
- 作者列表
- 摘要

**步骤2: 上传论文**
```
标题: Deep Learning for Image Classification
作者: Alice Zhang, Bob Li
摘要: This paper presents a novel deep learning approach...
```

**步骤3: 查看推荐**
系统推荐：
1. IEEE TPAMI (匹配度: 66.3%)
2. arXiv (匹配度: 31.0%)
3. Nature Communications (匹配度: 6.9%)

**步骤4: 选择期刊**
选择 arXiv（审稿快，接收率高）

**步骤5: 创建投稿**
输入arXiv账号信息，创建投稿记录

**步骤6: 跟踪进度**
在仪表盘查看投稿状态

## 🔧 API使用指南

### 直接调用API

如果你想通过编程方式使用系统，可以直接调用API：

#### 1. 上传论文

```bash
curl -X POST "http://localhost:8000/api/papers/upload" \
  -F "file=@paper.pdf" \
  -F "title=My Paper Title" \
  -F "authors=Author1, Author2" \
  -F "abstract=This is the abstract..."
```

#### 2. 获取期刊推荐

```bash
curl -X POST "http://localhost:8000/api/journals/recommend?paper_id=1&top_k=5"
```

#### 3. 创建投稿

```bash
curl -X POST "http://localhost:8000/api/submissions/create" \
  -H "Content-Type: application/json" \
  -d '{
    "paper_id": 1,
    "journal_name": "arXiv",
    "username": "user@example.com",
    "password": "password123"
  }'
```

#### 4. 查询投稿状态

```bash
curl "http://localhost:8000/api/submissions/1/status"
```

#### 5. 搜索期刊

```bash
curl "http://localhost:8000/api/journals/search?query=machine%20learning&top_k=10"
```

### 完整API文档

访问 http://localhost:8000/docs 查看交互式API文档（Swagger UI）

## 📊 系统架构

### 技术栈

**后端:**
- FastAPI (Web框架)
- SQLAlchemy (ORM)
- SQLite (数据库)
- Selenium (浏览器自动化)
- scikit-learn (机器学习)
- APScheduler (定时任务)

**前端:**
- 纯HTML/CSS/JavaScript
- 无需构建工具
- 响应式设计

**算法:**
- TF-IDF (关键词提取)
- 余弦相似度 (期刊匹配)
- 多维度评分 (综合推荐)

### 数据流

```
用户上传论文
    ↓
后端保存文件和元数据
    ↓
提取关键词 (TF-IDF)
    ↓
计算期刊相似度 (余弦相似度)
    ↓
综合评分排序
    ↓
返回推荐结果
    ↓
用户创建投稿
    ↓
加密存储凭证
    ↓
定时任务检查状态
    ↓
更新仪表盘
```

## 🐛 故障排除

### 问题1: 后端无法启动

**症状:** 端口被占用

**解决:**
```bash
# 查找占用端口的进程
lsof -ti:8000

# 杀死进程
kill -9 <PID>

# 重新启动
python main.py
```

### 问题2: 前端无法访问

**症状:** 页面无法打开

**解决:**
1. 检查前端服务器是否运行
2. 确认端口3001未被占用
3. 检查浏览器控制台错误

### 问题3: CORS错误

**症状:** 前端无法调用API

**解决:**
- 确保后端已配置CORS
- 检查API地址是否正确
- 清除浏览器缓存

### 问题4: 文件上传失败

**症状:** PDF上传报错

**解决:**
1. 检查文件大小（建议<20MB）
2. 确认文件格式为PDF
3. 检查data/papers目录权限

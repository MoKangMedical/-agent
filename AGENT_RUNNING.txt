📝 如何使用（3个简单步骤）：

步骤1️⃣: 放入你的论文PDF
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
方法A - 使用Finder（推荐）:
  1. 打开Finder
  2. 前往文件夹: ~/Documents/Papers
  3. 把PDF文件拖进去

方法B - 使用命令行:
  cp /path/to/your/paper.pdf ~/Documents/Papers/

示例:
  cp ~/Downloads/my_research.pdf ~/Documents/Papers/

步骤2️⃣: 等待Agent自动处理
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Agent会在下次扫描时（最多5分钟）自动:
  ✓ 发现新论文
  ✓ 提取关键词
  ✓ 推荐期刊
  ✓ 生成推荐报告

或者立即触发扫描（不等待）:
  cd ~/Desktop/论文投稿Agent/src/backend
  source venv/bin/activate
  python desktop_agent.py --folder ~/Documents/Papers --once

步骤3️⃣: 查看推荐报告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
在同一文件夹会生成:
  📄 {论文名}_推荐报告.txt  ← 期刊推荐
  📄 投稿状态总览.txt       ← 所有论文状态

查看方法:
  # 用文本编辑器打开
  open ~/Documents/Papers/your_paper_推荐报告.txt
  
  # 或在终端查看
  cat ~/Documents/Papers/your_paper_推荐报告.txt
